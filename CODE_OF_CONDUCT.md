# Code of Conduct

Parkio is a technical project with product, security, privacy, and operational
review surfaces. Discussions should stay respectful, evidence-based, and focused
on improving the repository.

## Expected Behavior

- Be direct, constructive, and specific.
- Assume good intent, but require evidence for technical claims.
- Respect privacy and security boundaries.
- Keep disagreements focused on code, docs, architecture, or operations.
- Credit prior work and avoid misrepresenting project status.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information, secrets, credentials, or sensitive user data.
- Filing public vulnerability details instead of following `SECURITY.md`.
- Spamming issues, pull requests, or discussions.
- Claiming deployments, users, revenue, partnerships, or certifications without
  evidence in the repository or operations records.

## Enforcement

Maintainers may edit or remove comments, close issues, reject pull requests, or
block accounts when behavior harms the project or community.

For sensitive conduct concerns, contact the maintainer privately through the
repository owner profile or the private channel documented by the project once
public contribution intake opens.
