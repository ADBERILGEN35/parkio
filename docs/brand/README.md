# Parkio Brand System

This directory defines Parkio's product identity for public-facing assets: `parkio.dev`, cloud startup applications, pitch decks, beta onboarding, social profiles, demo videos, screenshots, and future press material.

It is a design and brand source of truth, not an implementation package. Do not treat these files as CSS, React components, or production UI code.

## Canonical Positioning

Parkio is a community-powered parking intelligence platform that helps drivers find, share, verify, and manage real-world parking availability.

## Brand Attributes

- Modern.
- Reliable.
- Calm.
- Trustworthy.
- Community-powered.
- Technically strong.
- Privacy-conscious.
- Friendly.
- Professional.

## Avoid

- Crypto aesthetics.
- Gaming aesthetics.
- Corporate enterprise heaviness.
- Dark hacker visuals.
- Taxi branding.
- Generic map clone branding.

## Required Stage Language

Use this exact meaning in public assets:

- Application layer: certified for hosted-beta use.
- Live hosted beta: not yet deployed.
- Public production: not ready.
- Domain: `parkio.dev`.

Do not claim live beta, public launch, users, revenue, partnerships, market size, or program acceptance unless evidence exists in the repository.
