# Typography

## Recommended Fonts

### Primary UI and Body: Inter

Use Inter for product UI, landing pages, decks, and technical documents. It is readable, modern, neutral, and familiar in SaaS/product contexts without feeling overly corporate.

Google Fonts:

- `Inter`

### Display Alternative: Space Grotesk

Use Space Grotesk sparingly for hero headlines, pitch-deck section titles, or large campaign moments. It adds product character and technical confidence without becoming decorative.

Google Fonts:

- `Space Grotesk`

Do not use Space Grotesk for long body copy.

## Font Pairing

Recommended default:

- Headings: Space Grotesk.
- Body/UI: Inter.

Conservative fallback:

- Headings: Inter.
- Body/UI: Inter.

## Type Scale

| Role | Desktop | Mobile | Weight | Notes |
| --- | --- | --- | --- | --- |
| Hero | 56-64 px | 40-44 px | 700 | Use only once per page |
| H1 | 44-48 px | 34-38 px | 700 | Page title |
| H2 | 32-36 px | 28-30 px | 650 | Section title |
| H3 | 24-28 px | 22-24 px | 650 | Feature group |
| Body Large | 18-20 px | 17-18 px | 400 | Intro copy |
| Body | 16 px | 16 px | 400 | Default text |
| Small | 14 px | 14 px | 400/500 | Metadata |
| Caption | 12 px | 12 px | 500 | Labels and footnotes |

## Weight Hierarchy

- 700 for hero and major headings.
- 650 or 600 for section headings and emphasis.
- 500 for UI labels and buttons.
- 400 for normal body copy.

## Line Height

- Hero: 1.05-1.12.
- Headings: 1.15-1.25.
- Body: 1.5-1.65.
- UI labels: 1.2-1.35.

## Spacing

- Keep paragraph width between 58 and 72 characters.
- Avoid tight letter spacing; use default tracking.
- Give headings enough margin above to create clear scan paths.
- Buttons and form labels should not use display font sizes.

## Accessibility

- Body text should not drop below 16 px on web.
- Avoid all-caps body labels.
- Maintain strong contrast for all text.
- Do not rely on thin weights for key information.
