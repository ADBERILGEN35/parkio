# Copywriting Guide

## Core Message

Parkio helps drivers find, share, verify, and manage real-world parking availability.

## Headline Patterns

Use:

- "Community-powered parking intelligence."
- "Find parking signals from nearby drivers."
- "Share a spot. Help the next driver."
- "Photo-backed parking availability, built for trust."

Avoid:

- "Never search for parking again."
- "Guaranteed parking near you."
- "The Uber of parking."
- "AI solves parking."
- "Live in every city."

## CTA Patterns

Primary:

- Join beta waitlist.
- Request beta access.
- Follow development.

Secondary:

- View technical documentation.
- Read the FAQ.
- Contact founder.

Product actions:

- Share a spot.
- Verify availability.
- Claim spot.
- Report issue.
- Save Smart Return settings.

## Stage Copy

Short:

Parkio is in release-candidate / hosted-beta preparation.

Full:

Parkio is at `v1.0.0-rc1`. The application layer is certified for hosted-beta use. The live hosted beta is not yet deployed, and public production remains not ready.

## Trust Copy

Use:

- "Photo-backed submissions."
- "Community verification."
- "Moderation-supported trust."
- "Privacy-conscious location handling."
- "Short-lived signed media URLs."

Avoid:

- "Always accurate."
- "Automatically legal."
- "Fully anonymous" unless implemented and verified.
- "Production secure" unless public-production security is certified.

## Beta Copy

Use:

- "Private beta."
- "Measured beta cohort."
- "One constrained geography."
- "Not yet live."
- "TBD."
- "Not yet measured."

Avoid:

- "Public launch."
- "Available now."
- "Join thousands."
- "Citywide coverage."

## Error-Prone Claims

Do not claim:

- Active users.
- Revenue.
- Funding.
- Partnerships.
- Patents.
- Startup program acceptance.
- Market size.
- Public production readiness.

Use TBD or Not yet measured.
