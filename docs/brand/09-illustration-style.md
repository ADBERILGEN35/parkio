# Illustration Style

## Purpose

Illustrations should explain parking workflows and community signals. They should not replace real product screenshots once those exist.

## Style Direction

- Clean vector-like compositions.
- Soft geometric shapes.
- Light backgrounds.
- Subtle street-grid references.
- Small human/community cues.
- Product-like spot cards, pins, and verification signals.

## Subject Matter

Use illustrations for:

- A driver sharing a spot.
- A nearby driver discovering a verified spot.
- Community verification.
- Privacy-safe media handling.
- Hosted beta roadmap.
- Trust and moderation workflow.

## Avoid

- Cartoon mascots.
- Gaming badges.
- Dense map tiles.
- Taxi imagery.
- Dark cyber visuals.
- Generic startup people floating around dashboards.

## Color Usage

- Use neutrals and surfaces as the base.
- Use Parkio Teal for primary elements.
- Use Mobility Blue for technical/route cues.
- Use Signal Lime sparingly for positive highlights.
- Use Warning/Danger only for actual risk states.

## Detail Level

Illustrations should work at small section size. If the concept needs labels to be understood, simplify it.

## Motion Direction

If animated later:

- Slow, purposeful transitions.
- Route line drawing.
- Verified spot appearing.
- Notification card sliding in.
- Avoid bouncing, confetti, or game-like effects.
