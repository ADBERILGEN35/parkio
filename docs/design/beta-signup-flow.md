# Beta Signup Flow

The beta signup flow is the deeper application path for visitors who want to be considered for an early hosted-beta cohort.

## Purpose

Collect enough context to select useful beta testers without pretending Parkio has an open public launch.

## Eligibility Copy

Recommended intro:

> Parkio is preparing a focused hosted beta. This application helps identify testers whose parking needs and locations are useful for early validation. Submission does not guarantee access.

## Suggested Fields

Required:

- Email
- Consent to receive beta communication
- General city or area
- Primary device type
- Agreement that Parkio is not public-production ready

Optional:

- First name
- Parking use case
- How often parking uncertainty affects the user
- Typical parking context
- Willingness to provide feedback
- Accessibility or safety considerations

Do not request:

- Home address
- Exact workplace address
- Precise daily route
- License plate
- Payment information
- Sensitive demographic data

## Field Options

Primary device type:

- iOS
- Android
- Mobile web
- Desktop web
- Not sure

Parking use case:

- Campus or university
- Urban commuting
- Local errands
- Events
- Residential neighborhood
- Other

Parking frequency:

- Daily
- Several times per week
- Weekly
- Occasionally

Feedback willingness:

- Short surveys
- Email feedback
- Product interview
- Bug reports only
- Not sure

## Status Lifecycle

Use these statuses if a beta application workflow is implemented later:

- Submitted
- Reviewing
- Waitlisted
- Invited
- Not selected yet

Avoid:

- Accepted, unless there is a formal acceptance process.
- Customer, unless the person becomes a paying customer.
- Active user, unless usage is actually measured.

## Confirmation

Headline:

> Beta application received.

Copy:

> Parkio is preparing for hosted beta. We will use your response to plan early cohorts. Invite timing, supported areas, and cohort size are TBD.

Next actions:

- Follow development
- View FAQ
- View technical documentation

## Safety and Expectation Notes

The beta application should state:

- Parkio is not public-production ready.
- Drivers remain responsible for local parking rules and safe behavior.
- Beta features may change.
- Availability information may be incomplete or incorrect during testing.

## Privacy Notes

The form should explain:

- Why each field is requested.
- Whether the field is required or optional.
- How beta communication data will be used.
- Where the public privacy policy will live once published.
