# Landing Page Content Map

This map connects landing page content to its source documents so implementation can stay consistent with the repository.

## Canonical Inputs

- Startup positioning: `docs/startup/README.md`
- Executive summary: `docs/startup/00-executive-summary.md`
- Solution details: `docs/startup/03-solution.md`
- Technical overview: `docs/startup/08-technical-overview.md`
- Landing copy: `docs/startup/13-landing-page-copy.md`
- FAQ: `docs/startup/14-faq.md`
- Brand foundation: `docs/brand/01-brand-foundation.md`
- Brand voice: `docs/brand/03-brand-voice.md`
- Visual identity: `docs/brand/04-visual-identity.md`

## Section Map

| Landing section | Source material | Implementation notes |
| --- | --- | --- |
| Header | Brand docs, startup README | Use simple navigation and one visible primary CTA. |
| Hero | Startup README, landing copy, brand voice | Use canonical product description and honest stage copy. |
| Problem | Startup problem doc | No statistics unless sourced later. |
| Solution | Startup solution doc | Show the community-powered product loop. |
| How It Works | Startup solution doc | Use find, share, verify, return as the core sequence. |
| Features | Startup solution and FAQ | Keep feature names consistent: Smart Return, notifications, verification, reports, moderation. |
| Trust and Privacy | Startup FAQ, brand principles | Make privacy visible before beta conversion. |
| Technology Credibility | Technical overview, certification docs | Link out instead of overloading the page. |
| Hosted Beta | Startup roadmap, go-to-market | State preparation status and TBD invite timing. |
| FAQ | Startup FAQ | Use concise answers and link to longer docs if needed. |
| Footer | Brand docs, startup package | Include `parkio.dev`, documentation, contact, and stage note. |

## Required Copy Consistency

Use this description where a short product summary is needed:

> Parkio is a community-powered parking intelligence platform that helps drivers find, share, verify, and manage real-world parking availability.

Use this stage language:

> Parkio is currently at release-candidate / hosted-beta preparation stage and is not yet public-production ready.

Use this domain:

> parkio.dev

## Assets Needed Before Implementation

- Logo or wordmark direction translated into actual assets.
- Product screenshots or staged mock screenshots.
- OpenGraph preview image.
- Favicon set.
- Privacy and terms destination, even if initial pages are placeholders.
- Waitlist form backend or no-code form destination.

## Claims To Avoid

- Public launch is live.
- Beta is currently open to all.
- Parkio has users, revenue, customers, partners, patents, or startup-program acceptance.
- Parkio supports every city.
- Parkio eliminates parking uncertainty.
- Parkio tracks users only in a specific way unless documented by implementation.
