# Parkio Design Documentation

This directory translates the canonical startup package and brand system into implementation-ready page and flow guidance for `parkio.dev`.

These documents are design specifications only. They do not define React components, CSS, backend behavior, APIs, deployment, or analytics implementation.

## Source of Truth

- Product positioning: `docs/startup/`
- Brand foundation: `docs/brand/`
- Primary domain: `parkio.dev`
- Current stage: `v1.0.0-rc1` / hosted-beta preparation
- Public production status: not public-production ready

## Design Goal

The landing experience should help a visitor understand Parkio within 30 seconds:

- Parkio is a community-powered parking intelligence platform.
- It helps drivers find, share, verify, and manage real-world parking availability.
- It is technically mature for hosted-beta preparation.
- It is not yet a live public-production service.
- The next action is joining the beta waitlist, following development, contacting the founder, or reviewing technical documentation.

## Implementation Readiness Checklist

- Use `parkio.dev` consistently.
- Use the canonical product description from `docs/startup/`.
- Present hosted beta as preparation, not as a live public launch.
- Keep CTAs honest and beta-oriented.
- Link to technical documentation for reviewers who need diligence depth.
- Do not claim users, revenue, partnerships, public launch, startup-program acceptance, or unsupported metrics.
- Keep privacy and trust visible before asking for beta information.
